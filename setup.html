Getting started

Set up your AWS troubleshooting assistant.

Install the browser extension, open the AWS Management Console, and use the side panel to review supported visible errors. Local detection is designed to work without sending error details to an AI service.

1

Install the extension

Open the browser's official add-on store and install SameWindow AWS Assistant once its listing is available.

2

Open the AWS Management Console

Sign in to AWS normally, then navigate to the console page where you want to investigate a visible error.

3

Open the extension side panel

Click the SameWindow AWS Assistant icon in the browser toolbar and review detected errors and the investigation timeline.

4

Review before sharing

Local detections are intended to stay in the browser. If cloud diagnosis is available, enable it only when needed, sign in, review the diagnostic summary, and explicitly confirm before sending it.

5

Clear history when finished

Use the extension's clear-history control when you no longer need the saved investigation entries. Never include AWS passwords, access keys, secret keys, or session tokens in diagnostic text.
